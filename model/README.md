# Models

OpenVINO IR model files (`.xml` + `.bin`) are **not committed** to
this repository — they are downloaded separately.

See the top-level README for the `wget` commands:

- `face-detection-retail-0004` (input `[N,3,300,300]`)
- `mobilenet-v3-large-1.0-224-tf` (input `[N,3,224,224]`)

Both are publicly available OpenVINO IR models; no license restrictions
beyond their upstream terms.
